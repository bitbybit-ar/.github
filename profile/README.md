# BitByBit

**Custom software, bit by bit.** We're two siblings from Argentina building apps, browser extensions and automation, and shipping open source on Bitcoin, Lightning and Nostr.

🌐 [bitbybit.com.ar](https://bitbybit.com.ar)

## Open source

We build in public. Fork it, run it, open an issue.

| Project | What it is | Links |
| --- | --- | --- |
| **Obelisk** | Discord-style group chat that runs directly on Nostr relays. No backend, no accounts. | [Live](https://obelisk.ar) · [Code](https://github.com/obelisk-app/obelisk) |
| **CURSATS** | Lightning checkout for teachers: buyers pay in sats, sellers get pesos or sats. | [Live](https://cursats.bitbybit.com.ar) · [Code](https://github.com/bitbybit-ar/bitbybit-cursats) |
| **BitByBit Run** | Multiplayer browser racing game. Log in with Nostr, the winner gets zapped. | [Live](https://run.bitbybit.com.ar) · [Code](https://github.com/bitbybit-ar/bitbybit-run) |
| **BitByBit Arena** | Public challenges on Nostr, with NIP-58 badges that travel across clients. | [Live](https://arena.bitbybit.com.ar) · [Code](https://github.com/bitbybit-ar/bitbybit-arena) |
| **BitByBit Habits** | Family habit tracker: kids complete habits and earn real sats over Lightning. | [Live](https://habits.bitbybit.com.ar) · [Code](https://github.com/bitbybit-ar/bitbybit-habits) |

**We also contribute to** [Nostr WoT](https://github.com/nostr-wot/nostr-wot-extension), a Nostr browser extension with signing, an encrypted vault and a WebLN wallet, and [Mapping Bitcoin](https://mappingbitcoin.com), an open directory of places that accept Bitcoin.

## Work with us

We also build for businesses: web apps, browser extensions, AI-powered automation, SEO and ongoing support. Our own products include [teclas.ar](https://teclas.ar), a platform for music teachers.

Have something in mind? Start at [bitbybit.com.ar](https://bitbybit.com.ar).
